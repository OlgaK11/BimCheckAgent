BimCheckAgent

BimCheckAgent — учебный проект по разработке интеллектуального помощника для проверки BIM-данных и выявления несоответствий в проектной документации.

Проект разрабатывается на C# и .NET 10. Для объяснения найденных замечаний используется локальная языковая модель Qwen2.5 через Ollama.

🎯 Цель проекта

Создать инструмент, который помогает инженерам проверять данные строительных моделей, сравнивать их со спецификациями и быстрее разбираться в найденных несоответствиях.

✨ Текущие возможности

Загрузка данных модели из CSV-файла.

Загрузка спецификации из CSV-файла.

Проверка данных на наличие замечаний.

Сравнение элементов модели со спецификацией.

Выявление отсутствующих элементов и других несоответствий.

Формирование отчёта report.csv.

Объяснение замечаний с помощью локальной языковой модели Qwen2.5.

Использование инженерной базы знаний для повышения точности объяснений.

🧠 Как работает проект

Программа загружает данные модели и спецификации из CSV-файлов.

Проверяет данные по заданным правилам.

Сравнивает элементы модели со спецификацией.

Формирует список найденных замечаний.

Передаёт замечания локальной языковой модели для объяснения.

Использует инженерную базу знаний, чтобы предоставить ИИ дополнительный контекст.

Сохраняет результаты проверки в CSV-отчёт.

ИИ помогает объяснять замечания, но не заменяет инженерную проверку и не принимает окончательных проектных решений.

🚀 Запуск проекта

Требования

Windows

Visual Studio с поддержкой .NET 10

Установленный .NET 10 SDK

Ollama

Модель Qwen2.5:7b

Установка модели

Открой терминал и выполни команду:

ollama pull qwen2.5:7b

Запусти модель для проверки:

ollama run qwen2.5:7b

Запуск приложения

Склонируй репозиторий:

git clone <URL-репозитория>

Открой решение или проект в Visual Studio.

Подготовь CSV-файлы с данными модели и спецификации в формате, который ожидает приложение.

Убедись, что Ollama доступна локально и модель загружена.

Запусти проект.

Пути к файлам и требуемые столбцы CSV определяются текущей реализацией приложения.
